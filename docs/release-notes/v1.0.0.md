# OpenTrail mods 1.0.0 for Spintires: MudRunner

[English](#english) | [Русский](#русский)

Draft. Not published until the mods are tested in game.

## English

Nine single-player mods for Spintires: MudRunner (game files 0.6.8, base game and all four DLC). Not affiliated with Saber Interactive or Focus Entertainment.

### Files

| File | What it does |
|---|---|
| OpenTrail_Hyper_Power.zip | Engine torque x10, at most 1,000,000 (the game's limit), on all 36 trucks. Use instead of Powerful Engines. |
| OpenTrail_Powerful_Engines.zip | Engine torque x2.5. |
| OpenTrail_AWD_and_Diff_Lock.zip | All-wheel drive and a switchable diff lock for the 10 trucks that lack them. |
| OpenTrail_Deep_Fording.zip | No water damage or stalling in deep water (the damage box sits 1 m above the cab). Side effect: almost no hit damage to the cab. |
| OpenTrail_No_Damage.zip | Damage capacity 64,000, the game's maximum: trucks never get near broken. |
| OpenTrail_Infinite_Fuel.zip | 64,000 litre tanks, the game's maximum (fuel consumption is not in the game files). |
| OpenTrail_Grippy_Wheels.zip | Much better grip in mud and water for all 50 wheel types. |
| OpenTrail_Winch_Anchors.zip | Winch anchors on stumps and small trees that had none. |
| OpenTrail_Unlocked_Trucks.zip (295 MB) | Trucks and trailers locked on the maps are unlocked in a new game (6 maps). |
| OpenTrail_Workshop_Folders.zip | Seven folders for the MudRunner Editor (inherited base-game trucks). |

### Install

Unlocked Trucks is opt-in: it replaces six whole level files. Its first test build was unreadable for the game (Zip64 headers, fixed).

Close the game. Put the zips in a folder and add a line per package above `<MediaPath Path="Media.zip" />` in `%APPDATA%\SpinTires MudRunner\Config.xml`, for example `<MediaPath Path="D:/Games/OpenTrail/OpenTrail_No_Damage.zip" />`, in this order (top = highest priority): Hyper Power or Powerful Engines, AWD and Diff Lock, Deep Fording, No Damage, Infinite Fuel, Grippy Wheels, Winch Anchors, Unlocked Trucks. Or run `tools\install_local.py --apply` from the repository. The main menu must appear as usual.

Mods that change the same truck files carry the changes of the ones below them, so a mod used alone also brings those (Deep Fording alone also gives No Damage and Infinite Fuel). `tools\build_mods.py --only a,b` builds a package with exactly the mods you pick.

### Not included

No fog-of-war mod: the fog map exists only in saves and the profile. Winch length, winch force and fuel consumption have no setting in the game files.

## Русский

Девять модов для одиночной игры в Spintires: MudRunner (файлы игры 0.6.8, база и все четыре DLC). Не связано с Saber Interactive и Focus Entertainment.

### Файлы

| Файл | Что делает |
|---|---|
| OpenTrail_Hyper_Power.zip | Крутящий момент x10, но не больше 1 000 000 (предел игры), у всех 36 грузовиков. Вместо Powerful Engines. |
| OpenTrail_Powerful_Engines.zip | Крутящий момент x2,5. |
| OpenTrail_AWD_and_Diff_Lock.zip | Полный привод и включаемая блокировка у 10 грузовиков, где их не было. |
| OpenTrail_Deep_Fording.zip | Глубокая вода не повреждает и не глушит мотор (зона повреждений на 1 м выше кабины). Побочно: кабина почти не получает повреждений от ударов. |
| OpenTrail_No_Damage.zip | Запас прочности 64 000 - максимум игры: грузовик никогда не подходит к поломке. |
| OpenTrail_Infinite_Fuel.zip | Баки на 64 000 литров - максимум игры (расхода топлива в файлах игры нет). |
| OpenTrail_Grippy_Wheels.zip | Намного лучшее сцепление в грязи и воде у всех 50 типов колёс. |
| OpenTrail_Winch_Anchors.zip | Точки для лебёдки на пнях и маленьких деревьях. |
| OpenTrail_Unlocked_Trucks.zip (295 МБ) | Запертые на картах грузовики и прицепы открыты в новой игре (6 карт). |
| OpenTrail_Workshop_Folders.zip | Семь папок для MudRunner Editor (наследники грузовиков базовой игры). |

### Установка

Unlocked Trucks - по выбору: он подменяет шесть целых файлов уровней. Первая тестовая сборка этого пакета не читалась игрой (заголовки Zip64, исправлено).

Закрыть игру. Сложить zip в папку и добавить по строке на пакет над `<MediaPath Path="Media.zip" />` в `%APPDATA%\SpinTires MudRunner\Config.xml`, например `<MediaPath Path="D:/Games/OpenTrail/OpenTrail_No_Damage.zip" />`, в таком порядке (верхний главнее): Hyper Power или Powerful Engines, AWD and Diff Lock, Deep Fording, No Damage, Infinite Fuel, Grippy Wheels, Winch Anchors, Unlocked Trucks. Или запустить `tools\install_local.py --apply` из репозитория. Главное меню должно появиться как обычно.

Моды, меняющие одни и те же файлы грузовиков, несут правки тех, что ниже, поэтому мод в одиночку приносит и их (один Deep Fording даёт ещё No Damage и Infinite Fuel). `tools\build_mods.py --only a,b` собирает пакет ровно из выбранных модов.

### Чего нет

Мода без тумана войны: карта тумана есть только в сохранениях и профиле. Длины и силы лебёдки и расхода топлива в файлах игры нет.
