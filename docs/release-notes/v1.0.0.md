# OpenTrail mods 1.0.0 for Spintires: MudRunner

[English](#english) | [Русский](#русский)

## English

Nine single-player mods for Spintires: MudRunner (game files 0.6.8, base game and all four DLC) and tools that open maps, garages and trucks. Checked in game. Not affiliated with Saber Interactive or Focus Entertainment.

### Mods

| File | What it does |
|---|---|
| opentrail_hyper.zip | 36 new trucks "<truck> (Hyper)": engine torque x10 (at most 1,000,000, the game's limit) and every forward gear x2 faster. Instead of Powerful Engines. |
| opentrail_power.zip | 36 new trucks "<truck> (Powerful)": torque x3 and every forward gear x1.5 faster - felt in every gear. |
| opentrail_awd.zip | 10 new trucks "<truck> (AWD)": all-wheel drive and a switchable diff lock where the stock truck lacks them. |
| opentrail_ford.zip | 36 new trucks "<truck> (Deep Fording)": deep water does not damage or stall the engine. |
| opentrail_damage.zip | 36 new trucks "<truck> (No Damage)": damage capacity 64,000, the game's maximum. |
| opentrail_fuel.zip | 36 new trucks "<truck> (Big Tank)": fuel tank x4. |
| opentrail_grip.zip | Much better grip in mud and water for all 50 wheel types. |
| opentrail_winch.zip | Winch anchors on stumps and small trees. |
| opentrail_unlock.zip (295 MB) | Locked trucks in the map files are open in a new game (Flood, River, Valley, Ridge, Old-timers). |

The truck mods do not change the stock trucks: they add new trucks under their own names, picked in the truck slots or in the Proving Ground.

### Tools (`OpenTrail_Tools.zip`)

Needs Python 3 from python.org. **Close the game before any change.** Every tool shows the change first, writes only after "да" (yes) and makes a backup.

- `py tools\install_local.py --apply` - installs the eight packages that come in the zip (put `opentrail_unlock.zip` into `build\local` for Unlocked Trucks, then `--all --apply`). Backup `Config.xml.opentrail-<time>`; undo `--remove --apply`.
- "Собрать свой мод.bat" - your own set: several mods on one truck. Undo: `0`.
- "Открыть карты MudRunner.bat" - `1` maps (profile), `2` garages, `3` locked trucks on a map (map save), `4` undo profile, `5` undo map save. Backups: `UserProfile.stu.opentrail-<time>` and `%LOCALAPPDATA%\OpenTrail\MudRunner saves backup`.

Do not rename the zips: the game crashes on a package name longer than 16 characters. Single player only.

### Files

- `opentrail_*.zip` - the nine mods.
- `OpenTrail_Tools.zip` - the tools with eight mods inside.
- `OpenTrail_Workshop_Folders.zip` - seven folders for the MudRunner Editor (Steam Workshop, base-game trucks).

## Русский

Девять модов для одиночной игры в Spintires: MudRunner (файлы игры 0.6.8, база и все четыре DLC) и утилиты, которые открывают карты, гаражи и грузовики. Проверено в игре. Не связано с Saber Interactive и Focus Entertainment.

### Моды

| Файл | Что делает |
|---|---|
| opentrail_hyper.zip | 36 новых грузовиков «<грузовик> (Гипермощь)»: момент x10 (не больше 1 000 000 - предел игры) и каждая передача вперёд в 2 раза быстрее. Вместо Мощного мотора. |
| opentrail_power.zip | 36 новых грузовиков «<грузовик> (Мощный мотор)»: момент x3 и каждая передача вперёд в 1,5 раза быстрее - чувствуется на каждой передаче. |
| opentrail_awd.zip | 10 новых грузовиков «<грузовик> (Полный привод)»: полный привод и включаемая блокировка там, где у обычного их нет. |
| opentrail_ford.zip | 36 новых грузовиков «<грузовик> (Глубокий брод)»: глубокая вода не повреждает и не глушит мотор. |
| opentrail_damage.zip | 36 новых грузовиков «<грузовик> (Без поломок)»: запас прочности 64 000 - максимум игры. |
| opentrail_fuel.zip | 36 новых грузовиков «<грузовик> (Большой бак)»: бак в 4 раза больше. |
| opentrail_grip.zip | Намного лучшее сцепление в грязи и воде у всех 50 типов колёс. |
| opentrail_winch.zip | Точки для лебёдки на пнях и маленьких деревьях. |
| opentrail_unlock.zip (295 МБ) | Запертые в файлах карт грузовики открыты в новой игре (Наводнение, Река, Долина, Хребет, Old-timers). |

Моды грузовиков не меняют обычные грузовики: они добавляют новые под своими именами, их выбирают в слотах при старте карты или на полигоне.

### Утилиты (`OpenTrail_Tools.zip`)

Нужен Python 3 с python.org. **Перед любой правкой полностью закрыть игру.** Утилиты сначала показывают, что изменится, пишут только после «да» и делают резервную копию.

- `py tools\install_local.py --apply` - ставит восемь модов из архива (для Unlocked Trucks положить `opentrail_unlock.zip` в `build\local`, потом `--all --apply`). Копия `Config.xml.opentrail-<время>`; откат `--remove --apply`.
- «Собрать свой мод.bat» - свой набор: несколько модов на одном грузовике. Откат: `0`.
- «Открыть карты MudRunner.bat» - `1` карты (профиль), `2` гаражи, `3` запертые грузовики на карте (сохранение карты), `4` откат профиля, `5` откат сохранения. Копии: `UserProfile.stu.opentrail-<время>` и `%LOCALAPPDATA%\OpenTrail\MudRunner saves backup`.

Имена zip не менять: игра падает на имени пакета длиннее 16 символов. Только одиночная игра.

### Файлы

- `opentrail_*.zip` - девять модов.
- `OpenTrail_Tools.zip` - утилиты и восемь модов внутри.
- `OpenTrail_Workshop_Folders.zip` - семь папок для MudRunner Editor (Мастерская Steam, грузовики базовой игры).
