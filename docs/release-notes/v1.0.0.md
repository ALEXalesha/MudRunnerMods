# OpenTrail mods 1.0.0 for Spintires: MudRunner

[English](#english) | [Русский](#русский)

Draft. Not published until the mods are tested in game.

## English

Nine single-player mods for Spintires: MudRunner (game files 0.6.8, base game and all four DLC). Not affiliated with Saber Interactive or Focus Entertainment.

### Files

| File | What it does |
|---|---|
| opentrail_hyper.zip | 36 new trucks "<truck> (Hyper)": engine torque x10, at most 1,000,000 (the game's limit). |
| opentrail_power.zip | 36 new trucks "<truck> (Powerful)": engine torque x2.5. |
| opentrail_awd.zip | 10 new trucks "<truck> (AWD)": all-wheel drive and a switchable diff lock where the stock truck lacks them. |
| opentrail_ford.zip | 36 new trucks "<truck> (Deep Fording)": no water damage or stalling in deep water (the damage box sits 1 m above the cab). Side effect: almost no hit damage to the cab. |
| opentrail_damage.zip | 36 new trucks "<truck> (No Damage)": damage capacity 64,000, the game's maximum. |
| opentrail_fuel.zip | 36 new trucks "<truck> (Infinite Fuel)": 64,000 litre tank, the game's maximum (fuel consumption is not in the game files). |
| opentrail_grip.zip | Much better grip in mud and water for all 50 wheel types. |
| opentrail_winch.zip | Winch anchors on stumps and small trees that had none. |
| opentrail_unlock.zip (295 MB) | Trucks and trailers locked on the maps are unlocked in a new game (6 maps). |
| OpenTrail_Workshop_Folders.zip | Seven folders for the MudRunner Editor (new base-game trucks as full copies). |

### Install

Unlocked Trucks is opt-in: it replaces six whole level files. Its first test build was unreadable for the game (Zip64 headers, fixed).

Do not rename the zips: the game crashes on a package name longer than 16 characters before `.zip` (it copies the name of the archive a truck comes from into a 17-byte buffer).

Close the game. Put the zips in a folder and add a line per package above `<MediaPath Path="Media.zip" />` in `%APPDATA%\SpinTires MudRunner\Config.xml`, for example `<MediaPath Path="D:/Games/OpenTrail/opentrail_damage.zip" />`, in this order (top = highest priority): Hyper Power or Powerful Engines, AWD and Diff Lock, Deep Fording, No Damage, Infinite Fuel, Grippy Wheels, Winch Anchors, Unlocked Trucks. Or run `tools\install_local.py --apply` from the repository. The main menu must appear as usual.

The truck mods do not change the stock trucks: each adds new trucks under its own names (full copies of all 36 drivable trucks, base game and DLC, with the stock icon), so the game's own truck files stay untouched (replacing them crashes the game). Pick the new trucks in the truck slots when you start a map, or in the Proving Ground. For several changes on one truck: `tools\build_mods.py --only infinite_fuel,no_damage` builds trucks "<truck> (Infinite Fuel + No Damage)".

### Not included

No fog-of-war mod: the fog map exists only in saves and the profile. Winch length, winch force and fuel consumption have no setting in the game files.

### Установка

Unlocked Trucks - по выбору: он подменяет шесть целых файлов уровней. Первая тестовая сборка этого пакета не читалась игрой (заголовки Zip64, исправлено).

Не переименовывайте zip: игра падает, если имя пакета длиннее 16 символов до `.zip` (она копирует имя архива, из которого грузовик, в буфер на 17 байт).

Закрыть игру. Сложить zip в папку и добавить по строке на пакет над `<MediaPath Path="Media.zip" />` в `%APPDATA%\SpinTires MudRunner\Config.xml`, например `<MediaPath Path="D:/Games/OpenTrail/opentrail_damage.zip" />`, в таком порядке (верхний главнее): Hyper Power или Powerful Engines, AWD and Diff Lock, Deep Fording, No Damage, Infinite Fuel, Grippy Wheels, Winch Anchors, Unlocked Trucks. Или запустить `tools\install_local.py --apply` из репозитория. Главное меню должно появиться как обычно.

Моды грузовиков не меняют обычные грузовики: каждый добавляет новые под своими именами (полные копии всех 36 грузовиков базы и DLC, со значком от обычного), а файлы грузовиков игры остаются нетронутыми (их подмена роняет игру). Новые грузовики выбирают в слотах при старте карты или на полигоне. Несколько правок на одном грузовике: `tools\build_mods.py --only infinite_fuel,no_damage` собирает грузовики «<грузовик> (Бесконечное топливо + Без поломок)».

### Чего нет

Мода без тумана войны: карта тумана есть только в сохранениях и профиле. Длины и силы лебёдки и расхода топлива в файлах игры нет.
